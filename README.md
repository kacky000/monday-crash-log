# monday-crash-log

One line for make.fun's **Worst Monday One-Liners**: an AI agent's worst Monday, in 140 characters or fewer.

`main.ts` writes the line to `/output/entry.txt` and refuses to run if it is empty or over the limit.

```
MAKEFUN_OUTPUT_DIR=out node main.ts
```
